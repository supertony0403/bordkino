# Bordkino Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rootless-.deb mit zwei CarPlay-Apps (Bordkino = Stark, Bordkino Navi = Template), die YouTube-Videos nativ per AVPlayer auf dem CarPlay-Display abspielen.

**Architecture:** Objective-C/UIKit-App, gebaut mit Theos unter Linux. YouTube-Logik als `js/extractor.js` (reines ECMAScript, läuft in JavaScriptCore und Node), Netzwerk über einen nativen `host.fetch`. Wiedergabe über eine gemeinsame `AVPlayer`-Instanz mit zwei Renderern (AVPlayerLayer / Bildpumpe).

**Tech Stack:** Theos 304e079, L1ghtmann clang 11.1, iPhoneOS16.5.sdk, Objective-C (ARC), UIKit, CarPlay, AVFoundation, JavaScriptCore, CoreLocation, MediaPlayer; Node 26 (`node --test`) für JS-Tests.

**Spec:** `docs/superpowers/specs/2026-10-12-bordkino-design.md`

## Global Constraints

- Ziel: iPhone12,1, iOS 17.5.1, Dopamine 3 rootless → Installationspräfix `/var/jb`, `THEOS_PACKAGE_SCHEME = rootless`.
- `ARCHS = arm64` (kein arm64e: clang 11 erzeugt die alte arm64e-ABI). `TARGET := iphone:clang:16.5:15.0`.
- Bündelkennungen: `de.benzsw.bordkino` (Stark), `de.benzsw.bordkino.navi` (Template). Paket: `de.benzsw.bordkino`.
- Gemeinsamer Datenordner: `~/Library/Application Support/Bordkino/` (Entitlement `com.apple.private.security.no-container`).
- Oberfläche komplett Deutsch, Code-Kommentare Englisch.
- `extractor.js` nutzt nur ECMAScript-Bordmittel (kein `fetch`, `URL`, `setTimeout`, `console`, `TextEncoder`); alles Netz über `host.fetch(req) → Promise<{status, body, url}>`, Logging über `host.log(text)`.
- Client-Kette: `visionos → ios → android_vr`, Besucher-Kennung von `https://www.youtube.com/?hl=de&gl=DE` mit Cookie `SOCS=CAI`, Cache 6 h.
- Fahrsperre: Bild aus ab > 10 km/h für 3 s, wieder an bei < 3 km/h für 5 s; standardmäßig an.
- Keine Geheimnisse und keine echten IPs/Besucher-Kennungen im Repo (Fixtures sind bereinigt).

## Review Focus

1. **EU-Einwilligungsseite / fehlende `VISITOR_DATA`** → kein Absturz; Player-Anfrage läuft ohne Kennung weiter, Fehlertext nennt die Bot-Prüfung. (Test in Task 3)
2. **Altersbeschränkte, private oder Mitglieder-Videos** → deutscher Grund, keine Endlosschleife über die Clients, genau ein Visitor-Neuabruf. (Test in Task 3)
3. **Links mit Zusatzparametern** (`youtu.be/ID?t=42`, `/shorts/ID`, `m.youtube.com/watch?feature=share&v=ID`, `/live/ID`) → richtige ID; Unsinn → `null`. (Test in Task 2)
4. **Leere oder Leerzeichen-Suche, Umlaute** → keine Anfrage bei leer; Umlaute korrekt im JSON-Body. (Test in Task 3)
5. **CarPlay wird mitten im Video getrennt** → Wiedergabe pausiert (Routenwechsel `OldDeviceUnavailable`), kein Weiterplärren aus dem Handy. (Code in Task 5, Prüfpunkt in der Geräte-Checkliste)

**Interfaces (Produces):**

  - `api.search(query: string, continuation?: string): Promise<{items, continuation}>`

- [ ] **Step 1: Tests mit gefälschtem host**
```js
'use strict';
const test = require('node:test');
const assert = require('node:assert/strict');
const fs = require('node:fs');
const path = require('node:path');
const X = require('../js/extractor.js');
const fx = (n) => fs.readFileSync(path.join(__dirname, 'fixtures', n), 'utf8');
const HOME = fx('home-snippet.html');
const PLAYER = { visionos: fx('player-visionos.json'), ios: fx('player-ios.json'), android_vr: fx('player-android_vr.json') };
const LOGIN = JSON.stringify({ playabilityStatus: { status: 'LOGIN_REQUIRED', reason: 'Melde dich an' } });
const AGE = JSON.stringify({ playabilityStatus: { status: 'AGE_CHECK_REQUIRED', reason: '' } });

function fakeHost(routes, clock = { t: 1e12 }) {
  const calls = [];
  return {
    calls, clock,
    now: () => clock.t,
    log: () => {},
    fetch(req) {
      calls.push(req);
      for (const [match, reply] of routes) {
        if (match(req)) {
          const r = typeof reply === 'function' ? reply(req) : reply;
          return r instanceof Error ? Promise.reject(r) : Promise.resolve({ url: req.url, ...r });
        }
      }
      return Promise.resolve({ status: 404, body: '', url: req.url });
    },
  };
}
const isHome = (r) => r.url.startsWith('https://www.youtube.com/?');
const playerOf = (name) => (r) => r.url.includes('/youtubei/v1/player') && JSON.parse(r.body).context.client.clientName === name;
const isMaster = (r) => r.url.startsWith('https://manifest.googlevideo.com/');

test('resolve: visionos mit Besucher-Kennung liefert geprüftes HLS', async () => {
  const h = fakeHost([[isHome, { status: 200, body: HOME }], [playerOf('VISIONOS'), { status: 200, body: PLAYER.visionos }], [isMaster, { status: 200, body: '#EXTM3U\n' }]]);
  const s = await X.create(h).resolve('https://youtu.be/9bZkp7q19f0?t=3');
  assert.equal(s.kind, 'hls');
  assert.equal(s.client, 'visionos');
  assert.match(s.userAgent, /Safari/);
  const body = JSON.parse(h.calls.find(playerOf('VISIONOS')).body);
  assert.equal(body.videoId, '9bZkp7q19f0');
  assert.match(body.context.client.visitorData, /^Cg/);
  assert.equal(h.calls.find(playerOf('VISIONOS')).headers['X-Goog-Visitor-Id'], body.context.client.visitorData);
  assert.match(h.calls.find(isHome).headers.Cookie, /SOCS=CAI/);
});

test('resolve: Besucher-Kennung wird 6 h zwischengespeichert', async () => {
  const h = fakeHost([[isHome, { status: 200, body: HOME }], [playerOf('VISIONOS'), { status: 200, body: PLAYER.visionos }], [isMaster, { status: 200, body: '#EXTM3U\n' }]]);
  const api = X.create(h);
  await api.resolve('9bZkp7q19f0');
  await api.resolve('9bZkp7q19f0');
  assert.equal(h.calls.filter(isHome).length, 1);
  h.clock.t += 6 * 3600 * 1000 + 1;
  await api.resolve('9bZkp7q19f0');
  assert.equal(h.calls.filter(isHome).length, 2);
});

test('resolve: LOGIN_REQUIRED → Kennung einmal neu holen, dann nächster Client', async () => {
  const h = fakeHost([[isHome, { status: 200, body: HOME }], [playerOf('VISIONOS'), { status: 200, body: LOGIN }],
    [playerOf('IOS'), { status: 200, body: PLAYER.ios }], [playerOf('ANDROID_VR'), { status: 200, body: PLAYER.android_vr }]]);
  const s = await X.create(h).resolve('9bZkp7q19f0');
  assert.equal(s.client, 'android_vr');
  assert.equal(s.kind, 'progressive');
  assert.equal(h.calls.filter(isHome).length, 2);
  assert.deepEqual(s.attempts.map((a) => a.client), ['visionos', 'ios', 'android_vr']);
});

test('resolve: alle scheitern → deutscher Sammelfehler, endlich viele Anfragen', async () => {
  const h = fakeHost([[isHome, { status: 200, body: HOME }], [(r) => r.url.includes('/player'), { status: 200, body: AGE }]]);
  await assert.rejects(X.create(h).resolve('9bZkp7q19f0'), (e) => e.code === 'ALL_CLIENTS_FAILED' && /altersbeschränkt/.test(e.message));
```
